# Credit_Card_Financial_Weekly_Report
Power bi Dashboard
Project Objective:-
*I developed an interactive Power BI dashboard to track and analyze weekly credit card performance.
*Revenue Analysis: Monitored weekly revenue trends and WoW (Week-on-Week) growth.
*Customer Insights: Analyzed spending patterns based on demographics like age and job.
*Key Metrics: Tracked total transactions, interest earned, and card utilization.
*Segment Performance: Compared different card types (Blue, Gold, etc.) to identify top performers.
*Data-Driven Decisions: Provided actionable insights to help improve business profitability.
